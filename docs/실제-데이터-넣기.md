# 맥북에서 최신 코드 받고 실제 데이터까지 넣기

총무 엑셀(2026년 미투표자 현황)의 **실명 명단과 미투표 기록**을 Supabase 에 넣는 순서.
집에 와서 이 문서만 보고 따라 하면 된다.

> **`db push` 만으로는 데이터가 안 들어간다.**
> `db push` 는 표와 칸(스키마)만 만든다. 데이터는 4단계에서 따로 넣는다.

---

## 한눈에 보기

```bash
cd ~/…/footballbanghwa
git pull                                            # 1. 코드 받기
npm install                                         # 2. 새 패키지(exceljs)
npm run db:push                                     # 3. 스키마
npm run import:roster -- ~/Downloads/그엑셀.xlsx > import.sql   # 4. 적재 SQL 만들기
```

그리고 `import.sql` 을 **Supabase 대시보드 > SQL Editor** 에 붙여넣고 **Run**. 끝.

## 0. 먼저 확인할 것

| 확인 | 왜 |
|---|---|
| Node **20.12 이상** (`node -v`) | 그 아래에서는 `.env` 가 있을 때 `util.parseEnv is not a function` 으로 터진다 |

엑셀은 **손대지 않아도 된다.** 스크립트가 `전체명단` 시트의 3행 머리글을 읽어
`성명 / 연령대 / 날짜 칸`을 알아서 찾는다.

## 1. 코드 받기

```bash
cd ~/…/footballbanghwa
git checkout claude/early-soccer-team-app-2uexcc
git pull
```

## 2. 패키지 설치

```bash
npm install
```

엑셀을 읽는 `exceljs` 가 새로 들어갔다. 이건 **devDependency** 라 앱 번들에는 안 들어간다.

## 3. 스키마 올리기

```bash
npm run db:push
```

이번에 새로 가는 것:

- `attendance_status` 에 **`voted`** — "투표는 했는데 참석인지 불참인지 모른다"
- `age_band` 에 **`20`** — 명단에 20대가 둘 있다
- `ledger.months` / `ledger.photo_path` (연납·영수증), `inventory` 표(물품 재고)
- `lineups.quarter / side / photo_path` (쿼터별 두 팀 라인업), `lineup-photos`·`receipt-photos` 버킷

처음이라 `link` 부터 필요하면:

```bash
npx supabase login
npx supabase link --project-ref <프로젝트-ref>   # 대시보드 주소에 있다
npm run db:push
```

## 4. 적재 SQL 만들기

```bash
npm run import:roster -- ~/Downloads/그엑셀.xlsx > import.sql
```

끝나면 이런 줄이 뜬다:

```
회원 90명 · 집계한 주 24개 · 미투표 124건을 SQL 로 만들었어요.
```

**이 숫자가 엑셀과 맞는지 먼저 본다.** 여기서 어긋나면 SQL 을 돌리기 전에 잡는 게 싸다.

### 인자 (필요할 때만)

```bash
npm run import:roster -- <엑셀> [연도] [팀id] > import.sql
```

- **연도** — 안 주면 올해로 본다. 2027년에 2026년 엑셀을 넣으려면 `2026` 을 준다
- **팀id** — 안 주면 **가장 먼저 만든 팀**에 넣는다. 팀이 여럿이면 반드시 준다

팀 id 는 SQL Editor 에서:

```sql
select id, name from public.teams order by created_at;
```

## 5. Supabase 에 붙여넣기

1. 대시보드 > **SQL Editor** > New query
2. `import.sql` 을 통째로 붙여넣기 (VS Code 에서 `Cmd+A`, `Cmd+C`)
3. **Run**

키를 넣을 일이 없다. SQL Editor 는 이미 로그인한 사람이 쓰는 자리다.

**두 번 돌려도 안전하다.** 회원은 `이름+등번호`, 경기는 `날짜`, 참석은 `(경기, 회원)`
으로 맞춰 넣는다. 엑셀을 고치고 다시 돌리면 바뀐 것만 반영된다.

`begin; … commit;` 으로 감싸 놓아서 중간에 걸리면 **아무것도 안 들어간 상태로 되돌아간다.**

## 6. 맞는지 확인

`import.sql` 맨 아래에 대조 쿼리가 주석으로 있다. `--` 를 떼고 SQL Editor 에서 돌린다:

```sql
select m.name, count(*) filter (where a.id is null) as 미투표
  from public.members m
  cross join public.matches mt
  left join public.attendance a on a.match_id = mt.id and a.member_id = m.id
 where mt.date in ( … 집계한 주 … )
 group by m.name order by 미투표 desc;
```

엑셀 Sheet2 의 합계와 맞아야 한다. 2026-08-06 기준 상위 세 명:

| 이름 | 미투표 |
|---|---|
| 이경훈 | 17 |
| 박현진 | 13 |
| 김형주 | 10 |

줄 수로도 볼 수 있다 — **회원 90 · 경기 24 · 참석 2036줄** (= 90 × 24 − 124).

앱에서는 **더보기 > 출결 분석 > "답 안 한 순"** 이 같은 숫자를 보여 준다.

## 엑셀에 없어서 안 넣은 것

총무가 센 건 **답을 했나 안 했나**뿐이다. 참석·불참은 센 적이 없다.
그래서 없는 걸 지어내지 않았다:

| 엑셀 | DB |
|---|---|
| `O` 표시 | 참석 줄을 **안 만든다** = 미투표 |
| 표시 없음 | `voted` — 투표는 했는데 참석인지 불참인지 모른다 |
| 3월 전체·4월 초 (전원 빈칸) | 경기도 참석도 안 넣는다 = 집계 안 한 주 |
| 스코어 | 없음 |

`voted` 를 참석으로 올려 넣으면 안 된다. 다음 주 라인업이 그 거짓말 위에서 짜인다.

**집계를 안 한 주는 참석률·무응답 분모에서 빠진다.** 아흔 명이 다 같이 답을 안 한 게
아니라 그 주 체크를 건너뛴 것이라서다. 앱이 "응답이 한 건도 없는 경기"를 알아서 뺀다.

참석률도 **참석·불참을 밝힌 경기만으로** 낸다. 셀 게 없으면 `-` 로 나온다 —
지금 넣는 자료만으로는 대부분 `-` 가 맞다.

## 막혔을 때

**`팀이 없습니다. 앱에서 팀을 먼저 만들어 주세요.`**
앱에 로그인해서 팀을 만든 뒤 다시 Run. 아무것도 안 들어갔으니 그냥 다시 돌리면 된다.

**`팀 … 를 찾지 못했습니다.`**
넘긴 팀 id 가 없다. `select id, name from public.teams;` 로 확인.

**`'전체명단' 시트를 찾지 못했어요.`**
엑셀 시트 이름이 바뀌었다. `scripts/import-roster.mjs` 위쪽 `SHEET` 를 고친다.

**`머리글에서 성명·연령대·날짜 칸을 못 찾았어요.`**
머리글이 3행이 아니다. 같은 파일의 `HEADER_ROW` 를 고친다.

**`invalid input value for enum attendance_status: "voted"`**
3단계 `db push` 를 안 했거나 실패했다. 먼저 스키마부터.

**날짜가 한 해 밀려 있다**
연도 인자를 안 줬다. `npm run import:roster -- <엑셀> 2026 > import.sql`

**다시 처음부터 넣고 싶다**
그냥 다시 Run 하면 된다. 완전히 비우고 시작하려면 (돌이킬 수 없다):

```sql
delete from public.attendance where match_id in (select id from public.matches where team_id = '<팀id>');
delete from public.matches where team_id = '<팀id>';
delete from public.members where team_id = '<팀id>';
```
